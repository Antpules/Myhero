# 勇者邦邦

## Tkinter 用户界面

安装依赖并启动：

```powershell
python -m pip install -r .\requirements.txt
python .\app.py
```

界面使用 Python 内置的 Tkinter，无需安装 PyQt。启动后会自动扫描 ADB 设备，
选择设备、设置任务选项后点击“开始执行”，程序会在后台线程中加载 `resource` 资源包、
连接设备、执行所选 Pipeline，并把过程打印到日志区域。

执行期间可以点击“停止”。游戏画面需保持横屏 1280×720，或保持 16:9 并由
MaaFramework 将短边缩放到 720。

### 嘉年华刷取

助手只提供一个外部任务：

| 任务 | 入口节点 | 说明 |
| --- | --- | --- |
| **嘉年华刷取** | `嘉年华刷取` | 从混沌千域进入嘉年华，完成战斗并在结算后返回大地图 |

内部设置：

- **选择石板**：勾选后展开石板选择界面并自动选满三个；未勾选时直接点击“前往”。
- **选择绑定石板**：只有“选择石板”已勾选时才可用；勾选后跳过未绑定石板，
  未勾选时选择任意可添加的石板。
- **自动分解**：勾选后在开始刷取前执行一次自动分解，之后每完成 5 轮再执行一次。
- **循环次数**：输入 `1–999` 的正整数；每次完整完成进入嘉年华、战斗、结算并
  返回千域大地图后计为一轮，之后自动开始下一轮。

- **运行日志**：按级别着色（`✓` 成功、`!` 提示、`×` 失败），点“清空”可清空。
  选择石板过程中会实时打印每一块石板的名字，最后汇总成
  `已选择三个石板：A、B、C`。
- 日志面板会随窗口大小自动伸缩，窗口启动时自动居中且不会超出屏幕。

### 自动分解

在内部设置勾选“自动分解”后，程序会在开始刷取前识别并点击“拉吉酱”入口；进入
次元口袋后依次点击“一键分解”、筛选面板“确定”和左侧分解“确定”，随后持续关闭
所有“恭喜获得”弹窗。每次自动分解最多执行 3 次，结束后关闭口袋并返回千域大地图。
除开始前的一次外，每完成 5 轮嘉年华还会再执行一次。
每轮筛选后都会检查左侧分解“确定”按钮；若按钮未出现且仍停留在口袋界面，说明
已经没有满足筛选条件的装备，流程会立即正常结束，不再等待奖励或继续后续轮次。

## 石板放置功能

坐标与流程来自 `功能实现/石板放置功能.txt`，实现位于
`tools/stone_selector.py` + `resource/pipeline/stone.json`。

流程如下：

1. 在嘉年华挑战界面点击 `[988, 563, 64, 61]` 展开石板选择界面。展开时游戏会
   **默认选中第一个拥有的石板**，因此直接从石板条最左侧开始往右挑选；
2. 识别 `[328, 190, 313, 31]` 处的石板名字，并点击 `[422, 499, 121, 48]`
   的“添加”按钮，把石板名字暂存；
3. 依次点击每个石板，直到添加满 3 个不同的石板；**不足 3 个时才向右拖动**，
   从 `[852, 631]` 拖到 `[97, 638]` 查看后续石板，拖动后识别最右侧石板名字，
   连续 3 次相同即视为已经拖动到底；
4. 数量为 0 的石板可以点开查看但没有“添加”按钮，会被自动跳过；
5. 点击 `[988, 563]` / `[1064, 567]` / `[1126, 568]` 可选中已放置的石板并取消选中。

扫描石板条时会先读取每个图块中上部的高分位亮度。未拥有（数量为 0）或因已选石板而
发生冲突的图标会整体变暗，亮度低于阈值时直接跳过，不再点击并执行 OCR；
亮度正常的图标仍会通过“添加/取消”按钮二次确认，避免只依赖颜色判断。

### 选择绑定石板

启用“选择绑定石板”后，程序只添加名称末尾带 `（绑定）` 字样的石板：

- 识别原文里出现“绑定”即视为绑定石板，日志中显示的名字会去掉该后缀
  （例如 `异·传奇江东旧梦石板（绑定）` → `异·传奇江东旧梦石板`）；
- 未绑定的石板会被跳过，程序继续往右找，必要时向右拖动；
- 若整个石板列表里**全部是非绑定石板，则不添加任何石板**；如果最终不足 3 个
  （包括 0 个），程序会保留当前选择并直接点击“前往”进入战斗，不再中止任务。

> 石板选择是一个自定义动作（`SelectStones`），由 `app.py` 在加载资源后注册，
> 这样才能把识别到的石板名字实时推送到界面日志。

### 调试

`tools/stone_selector.py` 里的 `DEBUG = True` 会输出每个图块的识别详情
（名称 + 按钮文案），便于排查误判。

当前任务完成以下流程：

1. 如果嘉年华挑战面板已经打开，直接进入后续流程。
2. 否则在画面左上角识别“混沌千域”标题。
3. 标题识别成功后，点击嘉年华稳定点位 `[1016, 337]`。
4. 识别右侧面板顶部的“嘉年华”标题，确认界面已经打开。
5. 按内部设置选择石板，然后点击“前往”。
6. 识别“找到并击败BOSS”后点击智能施法；脚本只控制左下角摇杆。
7. 开战后每隔 5 秒检测一次智能施法按钮是否真的点亮，未点亮时补点一次并继续
   定时检测，直到确认开启；每次检测到的青色占比都会写进日志。
   若本轮启用了石板选择，识别到进入战斗后会等待 1 秒，再连续点击智能施法两次，
   两次点击间隔 1 秒。
8. 战斗中不再识别火车、不做 A* 寻路，改为固定巡逻走位：先在可行方向中随机
   挑一个方向走 1 秒，如此持续 10 秒；随后按上、右上、右、右下、下、左下、
   左、左上的顺时针顺序各走一遍，再按相反顺序逆时针各走一遍，每步 1 秒。
9. 随机阶段与两圈八向循环会一直重复，直到识别到 Boss 出口或结算界面；
   Boss 被击败后点击右侧出口，在结算界面点击“退出副本”，
   确认返回千域大地图后结束一轮。
10. 战斗中若左上玩家头像出现复活币标志，程序会点击头像，在复活确认框中点击
    “确定”使用复活币，然后继续战斗走位。

战斗状态机位于 `tools/battle_runner.py`，识别模板由
`tools/build_battle_templates.py` 从 `图片/` 中的五张战斗场景、Boss 与结算截图生成。
单轮最长保护时间为 15 分钟，等待进入战斗为 90 秒。战斗中途不再判断是否进入
新的战斗场景，走位会一直按上述循环重复。

智能施法状态检测读取按钮圆盘（中心 `[1240, 516]`、半径 `40`）内“亮青色”像素占比：
按钮开启时圆盘发青蓝色高光，关闭时是暗色灰剑图标。占比阈值由
`SMART_CAST_CYAN_RATIO = 0.05` 控制；若实机按钮配色变化导致误判，可在
`tools/battle_runner.py` 里调整该阈值或圆盘圆心。

## OCR 支持

项目已内置 MaaCommonAssets 的 `PP-OCRv6 tiny` 模型，可供后续文字识别节点直接使用：

```text
resource/model/ocr/
  det.onnx
  rec.onnx
  keys.txt
```

`resource/default_pipeline.json` 已配置默认 OCR 模型和阈值。新增节点时只需填写
`recognition: "OCR"`、`roi` 和可选的 `expected`。示例节点位于
`resource/pipeline/ocr.json`。

当前“混沌千域”地图判断继续使用模板匹配。该标题字体固定且带描边，模板匹配比
OCR 更快、更稳定；OCR 主要用于后续的关卡名称、次数、数值和弹窗文字。

## 使用

用支持 ProjectInterface v2 的 MaaFramework 通用前端打开本目录下的
`interface.json`，连接 ADB 设备或模拟器后运行“嘉年华刷取”，并在任务内部
设置中按需勾选“选择石板”和“选择绑定石板”。

控制器会把画面短边缩放为 720，因此当前 1280x720 素材可直接用于匹配。
游戏窗口需保持横屏 16:9，且不要改变游戏 UI 缩放比例。

若要从原始截图重新生成模板：

```powershell
python -m pip install Pillow
python .\tools\recrop_templates.py
python .\tools\build_battle_templates.py
```

`石板奖励槽.png` 取自实机截图中的石板奖励第一个槽位（`[988, 563, 64, 61]`），
用于在嘉年华面板中定位展开入口；`石板界面标志.png` 取自石板详情卡片中固定的
“石板效果”标题条，用于确认选择界面已经展开。更换界面美化后需要重新裁切。

## 打包成 exe

直接运行图形界面而不装 Python：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

脚本会在项目下创建 `.venv-build` 虚拟环境，安装 `requirements.txt` 与 PyInstaller，
再按 `Myhero.spec` 打包，产物是 `dist\勇者邦邦.exe`（单文件，约 93 MB）。
运行时会在 exe 同级目录生成 `config\`（MaaFramework 配置）和
`debug\`（日志与失败截图）。单文件版每次启动都要解包资源，第一次打开会慢几秒。

| 参数 | 作用 |
| --- | --- |
| `-OneDir` | 改打目录版 `dist\勇者邦邦\勇者邦邦.exe`，启动更快，适合本机长期使用 |
| `-Clean` | 打包前清空 `build\Myhero` 与 `dist\` |
| `-Console` | 保留控制台窗口，用于排查 Python 报错 |
| `-Python <路径>` | 指定打包用的解释器，默认使用 `.venv-build` |

`Myhero.spec` 会把这些内容一起收进 exe，因此目标机器不需要装 Python 或 MaaFramework：

- `resource\` 整个资源包（流水线、模板、OCR 模型）；
- `maa\bin` 下的原生库，如 `MaaFramework.dll`、`MaaToolkit.dll`、`onnxruntime_maa.dll`；
- `MaaAgentBinary`（推送到设备的 minicap / maatouch）。

`app.py` 与 `tools/battle_runner.py` 会自动区分源码运行和打包运行：打包后从
PyInstaller 的解包目录读取资源，日志目录则放在 exe 旁边。

## 调参

- “混沌千域”标题识别范围：`[0, 0, 300, 120]`
- 嘉年华点击点位：`[1016, 337]`
- 面板标题识别范围：`[880, 0, 400, 140]`
- 两个模板当前阈值均为 `0.82`

如果实际设备存在压缩、滤镜或色差，可先把阈值降到 `0.78`；若出现误识别，
则提高到 `0.88` 左右，并用实际设备的 MaaFramework 截图重新裁图。
